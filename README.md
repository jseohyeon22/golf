# 미니 골프

브라우저에서 바로 즐기는 5홀 미니 골프 게임입니다. HTML 파일 하나로 되어 있고, 외부 라이브러리 없이 Canvas로 그립니다.

**플레이:** https://jseohyeon22.github.io/golf/

## 조작법
공을 끌었다가 놓으면 반대 방향으로 날아가요 (새총 방식). 많이 끌수록 세게 칩니다. 마우스와 터치 모두 됩니다.

## 규칙
- 5개 홀, 각 홀마다 파(기준 타수)가 있어요
- 벙커(모래)에서는 공이 빨리 멈춰요
- 물에 빠지면 +1타, 친 자리에서 다시 쳐요
- 너무 빠르면 홀컵을 지나쳐요
- 최고 기록(총 타수)은 브라우저에 저장돼요
